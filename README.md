## What this is

I'm learning 11 songs from *Shawn* on guitar, and this site is where I keep the recordings. Open a song, press play, and hear where it's at. Each song has a status, so you can see at a glance what's finished and what's still a work in progress.


## What's on the site

- **Press play on any song.** A built-in player with a seek bar, plus a floating "now playing" bar that follows you as you scroll. Only one recording plays at a time.
- **See progress at a glance.** Eleven colored segments across the top, one per song. Tap a segment to jump straight to that song.
- **Filter by status.** Show all songs, or only the ones not started, in progress, or completed.
- **Hear the original.** Every song links to YouTube so you can compare my version with the real thing.
- **Recordings appear on their own.** Upload an audio file with the right name and the site finds it. No code to edit.
- **Light and fast.** One HTML file, no framework, no build step. It respects reduced-motion settings and works on phones and desktops.

### Status key

| Circle | Status | Meaning |
|:--:|---|---|
| ⚪ | Not started | Haven't begun learning it yet |
| 🟢 | In progress | Learning it right now |
| 🔵 | Completed | Can play it start to finish |

## Built with

- Plain **HTML, CSS, and JavaScript**, with no libraries and no build step
- **GitHub Pages**, publishing from the `main` branch and the `docs` folder
- The **GitHub API** to find new recordings in `docs/audio`
- The system font on each device, so text looks native and loads instantly
