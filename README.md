# Learning Shawn

Practice recordings as I learn 11 songs from Shawn Mendes' album *Shawn* on guitar.

**Listen here:** https://chasepatterson221.github.io/guitar-site/

## Adding a recording

1. Put the audio file in `docs/audio/`.
2. Add one line to that song's `clips` list in `docs/index.html`.
3. Commit and push. The site updates in about a minute.
